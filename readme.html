## Особенности темы - **Адаптивная вёрстка** — корректно отображается на всех устройствах (десктоп, планшеты, мобильные). - **Динамический контент** — информация о домиках, отзывы, цены и услуги управляются через админ-панель. - **Кастомные типы записей (CPT)** — созданы для удобного добавления и редактирования объектов глэмпинга. - **Интеграция с ACF (Advanced Custom Fields)** — гибкая настройка дополнительных полей (цены, галереи, особенности). - **Яндекс.Карты** — интерактивная карта с кастомными SVG-маркерами и выделенной территорией села Бритвино. - **Swiper-слайдеры** — для отзывов, услуг и фотогалереи. - **Аккордеон** с плавной анимацией для блока частых вопросов или отзывов. - **Оптимизация скорости** — LazyLoad карты и изображений. ## Технологии в теме - **PHP** (WordPress API) - **HTML5 / SCSS** (модульная структура) - **JavaScript (ES6+)** - **Advanced Custom Fields Pro** - **Yandex Maps API** - **Swiper.js** ## Установка и настройка 1. **Скопируйте папку с темой** в директорию `/wp-content/themes/` вашего WordPress. 2. **Активируйте тему** в админ-панели (Внешний вид → Темы). 3. **Установите и активируйте плагины:** - [Advanced Custom Fields Pro](https://www.advancedcustomfields.com/pro/) (или бесплатную версию, если функционала достаточно) - *При необходимости: Contact Form 7 для форм обратной связи* 4. **Настройте страницы:** - Создайте страницу "Главная" и назначьте ей шаблон `home.php`. - В настройках чтения укажите её как домашнюю страницу. 5. **Наполните контент:** - Добавьте домики через раздел "Домики" в админке. - Заполните отзывы, услуги, настройки карты в соответствующих полях ACF. ## Структура темы (основные файлы) houses-wordpress/ ├── style.css # Главный файл стилей с заголовком темы ├── functions.php # Регистрация CPT, ACF-полей, скриптов ├── front-page.php # Шаблон главной страницы ├── header.php / footer.php # Переиспользуемые части ├── template-parts/ │ ├── content-house.php # Шаблон вывода одного домика │ └── content-review.php # Шаблон вывода отзыва └── assets/ # Стили, скрипты, изображения (компилируются через Gulp) ## Разработка и сборка Если вы хотите вносить изменения в стили или скрипты: Автор V1nStery – разработка и интеграция на WordPress Лицензия Проект распространяется под лицензией MIT.
